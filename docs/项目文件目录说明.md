# docker-manager 文件目录说明

> 项目：Docker Stack Manager（GitHub `yanziruxue/docker-manager`）
> 文档版本：对应 **v1.15.1**
> 目的：一张表看清「哪个文件干什么」，便于定位改动位置、避免误删运行时数据。

---

## 0. 顶层速览

```
docker-unraid/
├── src/                 前端（React + Vite + Tailwind）
├── server/              后端（Express + dockerode，tsc 编译到 server/dist）
├── scripts/             构建 / 发布脚本
├── deploy/              交付物（linux SEA 单文件 + docker 镜像）
├── docs/                文档（本目录）
├── public/              前端静态资源
├── config/              运行时配置目录（内容由程序生成）
├── data/                运行时数据目录（ stacks / users / 设置…）
├── logs/                运行日志（按天切分）
├── build-upload/        待发布的 zip 交付包
├── dist/                前端构建产物（vite build 输出）
└── node_modules/
```

**三句话概括数据流**

```
浏览器 → src/（前端 UI）
        → /api → server/index.ts（路由）→ server/docker.ts（Docker 操作）
        → /ws/terminal（终端）· /api/.../stream（SSE 资源监控）
后端把前端 dist/ 内嵌进 SEA 单文件二进制 → deploy/linux/*.zip → 服务器
```

## 8. 构建链路（改动涉及哪些文件）

```
① npm run build:frontend
   src/**  ──vite──▶  dist/                        （前端产物）

② node scripts/build-binary.mjs
   server/** ──esbuild──▶ deploy/linux/bundle.js   （后端单文件 bundle，含 dist 内嵌）

③ SEA 注入（跨平台，无需 WSL）
   原始 Linux node ──cp──▶ deploy/linux/docker-manager-yanzi
   node --experimental-sea-config  deploy/linux/sea-config.json
   npx postject  ... NODE_SEA_BLOB deploy/linux/sea-prep.blob

④ python deploy/linux/make-package.py
   ──▶ deploy/linux/docker-manager-yanzi-linux-x64.zip ──cp──▶ build-upload/

⑤ 发布：scripts/push-via-api.mjs（源码）+ scripts/publish-release.mjs（Release）
```

## 9. 注意事项

| 项 | 说明 |
|---|---|
| **版本号三处同步** | `package.json`（源）、`vite.config.ts` 与 `scripts/build-binary.mjs`（`__APP_VERSION__` define）、`docs/CHANGELOG.md` |
| **不能直跑 `server/dist/index.js`** | `BUILD_BINARY` 由 esbuild define 注入，直跑会 ReferenceError |
| **SEA 构建不要跑 `deploy/linux/build.sh`** | 它复制当前 `node`（Windows 版）作为基底；本环境 WSL 被安全策略拦截，必须走「原始 Linux node + postject」手动流程 |
| **`deploy/linux/新建 文本文档.txt`** | 历史遗留空文件，可安全删除 |
| **发布前确认** | 发布 Release 属于对外动作，执行前须向用户确认 |
| **勿提交** | `.env`、`data/`、`logs/`、`dist/`、`build-upload/`、SEA 中间产物（均已 gitignore） |
