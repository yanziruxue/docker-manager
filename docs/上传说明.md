# 上传说明（仅上传，不重新构建）

适用：`build-upload/docker-manager-yanzi-linux-x64.zip` 已打好，只把它推到 GitHub Releases。
完整「构建 + 上传」见 `docs/发布与OTA升级指南.md`。

## 前置

- Tag 必须带 `v`（如 `v1.15.19`）且与 `package.json` 版本号一致，否则应用内 `compareVersion` 比对不上。
- Release 勿勾 **Draft / Pre-release**，否则 `releases/latest` 取不到，OTA 发现不了新版本。
- Token 只在 `.env` 的 `GITHUB_TOKEN` 里，**不写进文档和代码**（`.env` 已在 `.gitignore`）。

## 一键发布（推荐）

```bash
cd /d/AI/WorkBuddy/docker-unraid
set -a && source .env && set +a                                     # 加载 GITHUB_TOKEN
node scripts/push-via-api.mjs --msg "release: vX.Y.Z — 说明"        # 推源码（绕过 git 端口封锁）
npm run release                                                     # 创建 Release + 上传 zip
```

Windows CMD 用 `set GITHUB_TOKEN=ghp_xxx` 代替 `source .env`。

## 只覆盖已有 Release 的 asset

```bash
gh release upload v1.15.19 build-upload/docker-manager-yanzi-linux-x64.zip \
  -R yanziruxue/docker-manager --clobber
```

## 校验

```bash
gh release view v1.15.19 --repo yanziruxue/docker-manager --json tagName,assets
```

OTA 可发现性：确认 `/repos/yanziruxue/docker-manager/releases/latest` 返回的就是刚发的 tag。
