## 需求明细

### R5 — 仪表盘资源监控实时刷新（P0）

**原始描述**：仪表盘的资源监控改为实时刷新，不要 5s 一次。

**实现方案**：
- 轮询间隔从 5000ms 改为 **1000ms**（`src/App.tsx`）。经评估 WebSocket 流式推送改动大且 Docker stats 引擎本身约 1s 才推送一次快照，1s 轮询体感等同于实时。
- 卡片文案"实时刷新 5s"改为"实时刷新"。

**验证**：tsc 编译通过；仪表盘页活跃时每秒请求一次 `/api/engines/:id/resource-stats`。

### R3 — 图标列独立 + 图标传导（P0）

**原始描述**：容器管理页列显隐对图标操作的开关状态一直显示"显示"；WebUI Labels 设置图标后容器管理页对应容器图标不显示。

**根因**：
1. 图标嵌在"容器名称"列内渲染，无独立的显隐控制，开关无效。
2. `container.icon` 字段从未被赋值，堆栈 webuiLabels 未交叉引用到容器。

**实现方案**：
- 图标独立成列（表头新增"图标"列，受列选择器控制）。
- App.tsx `loadEngineData` 中按 服务名/container_name 匹配，将 stack.webuiLabels 的 iconUrl/webuiUrl 写入容器对象。

### R1 — 端口映射格式统一（P0）

**原始描述**：`0.0.0.0:8807:8080/tcp` 和 `:::8807:8080/tcp` 应合并显示为 `8807:8080/tcp`。

**决策**（用户确认）：无宿主机映射的内部端口不显示；有映射的显示 `8807:8080/tcp`。

**实现方案**：
- `src/transforms.ts`：host 字段去掉 IP 前缀，按完整映射去重（IPv4/IPv6 双绑定合并为一条），无 PublicPort 的条目过滤。
- `server/docker.ts`：堆栈容器列表同样按 `${PublicPort}:${PrivatePort}/${Type}` 去重生成。

### R4 — 堆栈端口列合并（P0）

**原始描述**：堆栈管理页高级/基本视图的"端口""宿主机端口"两列合并为"端口"一列。

**实现方案**：全链路删除 hostPorts 字段（server/docker.ts、types.ts、transforms.ts、Stacks.tsx 表头/表体），仅保留合并格式的"端口"列。

### R10 — 堆栈操作菜单中英切换（P1）

**原始描述**：按图 1 实现 10 项菜单（Compose Up/Stop/Restart/Down/Check Updates/Force Update/Edit Stack/View Logs/Delete Stack），菜单显示英文列或中文列其中之一，可在设置中心切换。

**实现方案**：
- 新增设置项 `docker.menuLanguage`（"en" | "zh"，默认 en），后端 settings.ts 默认值 + 前端类型同步。
- Stacks.tsx 增加 `L(en, zh)` 翻译辅助函数，堆栈菜单按图 1 顺序组织：Compose Up / Stop / Restart / Down / Check Updates / Force Update / Edit Stack / View Logs / Delete Stack，Build 类和 Terminal/Backup/Duplicate/Open WebUI 作为扩展功能保留在分隔符之后。
- 新增"查看日志"功能：StackLogModal 弹窗，可选择堆栈内运行容器和日志行数查看。
- 设置页"Docker 全局配置"下新增"菜单显示语言"选择器。

### R11 — Stack 编辑器 Unraid 风格（P1）

**原始描述**：编辑堆栈页面 UI 按图 2/3/4 改为 Unraid 风格（COMPOSE/.ENV/LABELS/SETTINGS 标签、底部 PROJECT DIR/EDITING FILE/OKAY/APPLY/CLOSE 状态栏、LABELS 服务卡片式、ENV 空状态带 CREATE .ENV TEMPLATE 按钮）。

**实现方案**：
- 标签改为大写：COMPOSE / .ENV / LABELS / SETTINGS。
- COMPOSE 页 yml 内容放入带边框圆角的框内，YAML 校验状态内嵌于框底部。
- ENV 页空状态显示"CREATE .ENV TEMPLATE"按钮，点击自动生成模板（含 COMPOSE_PROJECT_NAME/TZ/PUID/PGID 及各服务端口变量骨架）。
- 底部状态栏：左侧 PROJECT DIR（compose 文件所在目录）+ EDITING FILE（随标签切换），右侧 OKAY（保存并关闭）/ APPLY（保存）/ CLOSE（关闭）按钮。

### R2 — WebUI Labels 识别 container_name（P1）

**原始描述**：WebUI Labels 服务名识别 compose 中的 container_name；yml 内容改动实时识别。

**实现方案**：重写 `parseComposeServices`——解析 services 下每个服务时同时检测 `container_name:` 属性，声明了 container_name 时优先返回 container_name（与实际 Docker 容器名一致）；LABELS 标签页识别状态条每次渲染实时解析当前 composeContent。

### R7 — Compose 模式与默认参数分离（P2）

**原始描述**：系统设置-Docker 全局配置中，Compose 命令模式和默认参数分开两个显示框。

**实现方案**："默认参数"卡片（重启策略/网络模式/轮询间隔/环境变量）与新增"Compose 命令"卡片（命令模式+检测+菜单语言）拆分为两张独立 Card。

### R6 — 通知中心增加操作记录（P2）

**原始描述**：通知中心增加操作记录功能。

**实现方案**：
- 新建 `src/opLog.ts`：localStorage 持久化的前端操作日志（最多 500 条），记录 action/target/status/detail/engineId/timestamp。
- Notifications.tsx 增加"通知 | 操作记录"双 Tab；操作记录 Tab 提供搜索、状态筛选、清空功能。
- 已接入的操作点：堆栈 启动/关闭/拉取/重启/构建/删除/备份、堆栈内容器操作、容器管理页 启动/停止/重启/删除、镜像删除/悬空清理。成功与失败均记录。
